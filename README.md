여정잇다 (Travel Together) 🧳


AI 기반 맞춤 여행 일정 생성 및 공유 커뮤니티 플랫폼



여행 조건(지역, 예산, 인원, 날짜)만 입력하면 AI가 여행 일정 초안을 생성해주고,
완성한 여행 계획을 게시판에 공유하며 소통할 수 있는 서비스입니다.


Java 부트캠프 팀 프로젝트 (5인)
개발 기간: [2026.06 ~ 2026.07]
원본 팀 레포지토리: https://github.com/nanchano0607/travel_plan

<제가 담당한 역할> 
1.게시판부문에서 게시글 생성,수정 및 삭제 기능 구현
2.게시글 좋아요 토글 기능 구현 
3.마이페이지 UI 개발참여
4.게시판 부문 게시글에 이미지 첨부 및 마이페이지에 존재하는 여향계획 첨부 기능 구현
